### 목표
데이터에서 마케팅 소재(SNS 게시물·포스터·배너·OG 이미지·명함·크기 일괄 변형)와 상세페이지 코드까지 이어지는 파이프라인 — RESEARCH_SOURCES-02가 정의한 영역의 편입. 단 -02의 "웹사이트 레이아웃·랜딩페이지" 영역은 새 기능이 아니라 **P1 파이프라인 담당**(중복 구현 금지). 베타 공개 여부와 구독 서비스 전환은 이 시점에 사용자가 결정.

### 기능
- [ ] 마케팅 소재 파이프라인 (1차 경로 = 무료·로컬·Node): 데이터 → Satori(JSX→SVG) → Sharp(PNG/WebP 변환 + SNS 규격 일괄 리사이즈) — SNS 카드·포스터·배너·OG 이미지·**명함**(구조화 데이터 반복이라 템플릿 방식과 정합 — Canva Autofill 제외의 무료 대체 경로). 자료 -02 §13·14·24가 공식 안내
- [ ] 한글 오픈 라이선스 폰트(OFL — Pretendard 또는 Noto Sans KR) 번들/다운로드 단계: **Satori는 폰트 파일 명시 로드 필수**(시스템 폰트 자동 사용 불가 — 공식 README) — 누락 시 한글 렌더 실패. "임의 외부 폰트 금지" 규칙의 허용 예외로 OFL 폰트를 지정 — **P2 폰트 파이프라인(A)의 폰트·대장을 재사용**(중복 구현 금지)
- [ ] 소재 전용 검증 기준: 규격 크기·포맷·용량 체크 (웹 코드용 게이트와 별도 — axe·뷰포트 검사는 이미지 산출물에 부적용)
- [ ] 라이선스 게이트(자산 대장 확장): **P2에서 생성된** `ASSET-LEDGER.csv`(파일명·종류·출처URL·라이선스·상업이용·출처표시·AI생성여부·날짜)를 이미지·소재 자산으로 확장 + `ATTRIBUTION.md` 자동 생성 — 자료 -03 §23의 15종 파일을 개인 킷 규모로 3종 압축(YAGNI)
- [ ] AI 생성 이력 자동 기록: 소재 생성 시마다 모델·프롬프트·날짜·사람 편집 부분을 `AI-GENERATION-LOG.md`에 자동 append — 이력은 생성 시점에만 정확히 남길 수 있음(자료 -03 §9, 미국 저작권청 AI 지침)
- [ ] 유료 API 어댑터(옵션): Bannerbear·Placid·Creatomate·Firefly·Recraft·Ideogram — 도입 시 요금제·약관 확인 필수. **Canva Autofill은 Enterprise 조직 조건(자료 -02 §3 명시)이라 개인 킷 경로에서 제외.** **로고 생성은 유료 어댑터 전용(Recraft 벡터·Ideogram 타이포) — 생성형 API가 필수라 무료 1차 경로가 실제로 존재하지 않음(없는 것을 없다고 명시)**
- [ ] 상세페이지 파이프라인: 상품 데이터(CSV/JSON) → 카피 생성 → 페이지 코드 → 동일 검증 게이트 (자료 -01 18-3 흐름)
- [ ] MCP 서버 래퍼 — 멀티 클라이언트 (2026-07-19 사용자 결정): 코어 엔진(파이프라인·검증·리포트 조회)을 MCP 도구로 노출, open 대시보드 로컬 서버와 공유(O-Brain의 대시보드+MCP 동거 구조 재사용). 1순위 = Claude Desktop(.mcpb 원클릭 설치, 공식 지원 확인됨). **한계 정직 고지: 완료 차단은 Claude Code 훅 전용 — 타 클라이언트는 판정 제공까지** (01 능력 매트릭스)
- [ ] 베타 공개 준비: 전체 문서 세트 (01 §8 필수 목차 11종 — 설치·준비물·빠른 시작·사용법·명령어·워크플로우·보안/데이터 흐름·아키텍처·파일 위치·트러블슈팅·FAQ·법률, 왕초보 눈높이 + **문서만 보고 따라 하는 새 세션 리허설 1회 통과**) + ScanCode 1회 스캔(라이선스·저작권 고지 JSON → ATTRIBUTION.md 갱신 — 자료 -03 §18. **공개 시점 전용, 상시 게이트에는 미포함**) + **시크릿 스캔(코드·문서·판정서·Git 이력 포함 — 01 §6 Must)** + GitHub secret scanning·Dependabot 활성화
- [ ] 라이선스 확정·법률 산출물 (01 §7 — 공개의 전제 조건): 사용자+법무가 킷 라이선스 확정(추천 Apache-2.0·저작권자 표기 결정) → LICENSE 전문·(필요 시) NOTICE 생성 → README(한국어)·README.en.md·가이드에 사용 허용 범위(수정/복제/포크/재배포/판매/납품 O/X 표)·책임 제한·보증 없음·외부 자료 주의를 왕초보 눈높이로 일관 반영 → 의존성 라이선스 실측 확인 결과를 ASSET-LEDGER에 기록
- [ ] 반응 좋으면 구독 서비스화 검토 — **사용자 결정 사항** (이때 CLI 추출·요금·법무 검토가 처음 필요해짐)

### 주의사항
- AI 생성 로고는 실사용 전 유사 상표·저작권 검토 필수 (자료 -02 §9 경고의 규칙 승격) — 참고용이며 법적 효력을 보장하지 않음, 상표 사용 전 변리사·변호사 확인 권장
- 공개 시 저작권 불명 에셋·시크릿 포함 여부 스캔 필수
- 라이선스·법률 점검 자동화는 참고용 보조 도구이며 침해 여부 확정·법적 효력을 보장하지 않음(자료 -03 스스로 명시) — 상용·공개 전 변리사·변호사 등 전문가 확인 권장
