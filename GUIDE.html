이 문서를 읽기 전에 알아두면 좋은 것 (용어 풀이)

용어 쉬운 설명
AI 사람처럼 대화하며 작업을 대신해주는 컴퓨터 프로그램. 이 가이드에서는 "Claude"라는 AI를 씁니다.
Claude Code Claude(AI)와 대화하면서 컴퓨터 작업(파일 만들기, 코드 짜기 등)을 시킬 수 있는 프로그램. 이 가이드의 모든 작업은 이 프로그램 안에서 이루어집니다.
터미널 / 명령 입력 창 마우스 클릭 대신 글자로 명령을 입력해서 컴퓨터에게 일을 시키는 화면. Claude Code를 실행하면 자동으로 이런 화면이 뜨는데, 무섭게 생각하지 않으셔도 됩니다 — 이 가이드가 시키는 대로 글자만 그대로 입력하면 됩니다.
플러그인 Claude Code에 새 기능을 추가하는 부품 같은 것. 이 가이드에서 설치할 "SoDam-Design-Kit"이 바로 그 플러그인입니다.
슬래시 명령(/로 시작하는 명령) Claude Code 대화창에 /를 입력하면 미리 정해진 작업을 실행할 수 있는 특수 명령. 예: /plugin
폴더 / 디렉터리 컴퓨터 안에서 파일들을 담아두는 봉투 같은 것. Windows 탐색기에서 보이는 노란색 아이콘이 폴더입니다.
경로(path) 어떤 파일이나 폴더가 컴퓨터 안 "어디에" 있는지를 글자로 적은 주소. 예: D:\내폴더\하위폴더
Figma 화면 디자인(버튼, 화면 배치 등)을 그리는 데 쓰는 웹 서비스. 디자이너들이 많이 씁니다.
코드 컴퓨터가 실행할 수 있는, 프로그래밍 언어로 작성된 글자들의 집합. 이 킷은 Figma 디자인을 코드로 자동으로 바꿔줍니다.
브라우저 인터넷 화면을 보여주는 프로그램(크롬, 엣지 등). 이 킷은 만든 코드가 진짜로 브라우저에서 잘 나오는지 자동으로 확인합니다.

이 도구로 무엇을 할 수 있나요? (한 줄 요약)

Figma로 그린 디자인 화면(예: 버튼 하나)을, "진짜로 작동하는지 컴퓨터가 직접 확인한" 코드로 자동으로 바꿔줍니다. 사람이 "이거 코드로 잘 됐어?"라고 눈으로 대충 확인하는 대신, 이 도구가 실제 브라우저를 띄워 "정말로 화면이 제대로 나오는지, 장애인분들도 잘 쓸 수 있는지, 휴대폰/태블릿/PC 화면에서 다 괜찮은지"까지 자동으로 검사하고, 검사에 통과해야만 "다 됐다"고 말할 수 있게 만들어져 있습니다.

시작하기 전에 준비할 것 4가지

아래 4가지가 전부 다 준비되어 있어야 다음 단계로 넘어갈 수 있습니다. 하나씩 확인해보세요.

① Claude Code가 설치되어 있나요?

  • 이미 이 가이드를 Claude Code 안에서 보고 계신다면 준비 완료입니다. 아니라면 claude.com/claude-code 공식 페이지의 안내를 따라 먼저 설치하세요.

② Node.js가 설치되어 있나요?

  • Node.js는 이 도구가 내부적으로 사용하는 프로그램 실행기입니다.
  • 확인 방법: Claude Code 대화창에 아래 글자를 그대로 입력해보세요.
    node -v
  • 성공 기준: v22.19.0처럼 v로 시작하는 숫자가 나오면 성공입니다. 만약 "찾을 수 없다", "명령을 인식할 수 없다" 같은 메시지가 나오면 nodejs.org에서 "LTS"라고 적힌 버전을 다운로드해 설치한 뒤 다시 확인하세요.

③ "대상 프로젝트"가 준비되어 있나요?

  • 이 도구가 코드를 만들어 넣을 프로젝트가 미리 있어야 합니다. 조건: Next.js + Tailwind CSS + shadcn/ui로 만들어진 프로젝트.
  • 이미 이런 프로젝트가 있다면 그 폴더의 경로(주소)를 메모해두세요. 없다면, Claude Code에게 "Next.js + Tailwind + shadcn/ui로 새 프로젝트를 만들어줘"라고 자연어로 요청해 먼저 준비하세요.

④ Figma에 접근할 수 있나요?

  • 코드로 옮길 디자인이 Figma에 있어야 합니다. claude.ai에 Figma가 이미 연결되어 있다면 그대로 쓰면 되고, 안 되어 있다면 Claude Code에게 "Figma에 연결해줘"라고 요청하면 로그인 절차를 안내받을 수 있습니다.
  • Figma 계정은 무료(가장 기본 등급)여도 괜찮습니다. 다만 한 달에 6번만 디자인을 읽을 수 있는 제한이 있으니, 진짜 확인이 필요한 화면 위주로 아껴 쓰는 것을 추천합니다.

4가지가 다 준비됐다면 아래 "설치하기"로 넘어가세요. 하나라도 없다면 그것부터 먼저 준비해야 합니다.

설치하기 (한 번만 하면 됨)

⚠️ 이 설치 방법은 이 도구가 아직 일반에 공개되지 않고, 내 컴퓨터의 폴더를 직접 지정해서 설치하는 방식일 때 기준입니다. 이 방식은 나중에 바뀔 수 있습니다.

1단계: 마켓플레이스 등록

Claude Code 대화창에 아래처럼 입력합니다 (<이 저장소 폴더의 전체 경로> 자리에는 실제 이 킷이 있는 폴더 경로를 넣으세요 — 예: D:\AI_Dev_Work\2026y\26y_07m_26d_SoDam-Design-Kit):

/plugin marketplace add D:\AI_Dev_Work\2026y\26y_07m_26d_SoDam-Design-Kit

✅ 이 화면이 보이면 성공: "마켓플레이스가 추가되었습니다" 같은 확인 메시지가 나옵니다.

2단계: 플러그인 설치

/plugin install sodam-design-kit@sodam

✅ 이 화면이 보이면 성공: "Installed" 또는 "설치되었습니다" 메시지가 나옵니다.

3단계: Claude Code를 완전히 껐다가 다시 켜기

  • 그냥 새로고침이 아니라, 창을 완전히 닫고 다시 실행해야 합니다.
  • 왜 필요한가요? Claude Code가 방금 설치한 내용을 제대로 알아차리려면 "다시 시작"이 필요하기 때문입니다(이건 흔한 함정이라 미리 알려드립니다).

4단계: 필요한 부품 내려받기 (최초 한 번만)

Claude Code 대화창에서, 이 킷 저장소 폴더 자체(방금 1단계에 입력한 그 경로)로 이동해 아래를 입력합니다:

npm install
  • 이 명령은 "실제 브라우저에서 화면을 확인하는 도구"와 "접근성 검사 도구"를 내려받습니다. 시간이 조금 걸릴 수 있습니다. ✅ 이 화면이 보이면 성공: 오류 없이 명령이 끝나고, 다시 입력할 수 있는 상태로 돌아옵니다.

💡 함정 주의: 어떤 프로그램들은 설치하면 내문서\AppData\... 같은 별도 위치에 복사본을 만드는데, 이 도구는 그렇지 않습니다. 1단계에서 지정한 원본 폴더를 그대로 계속 사용합니다. 그러니 "설치된 폴더"를 따로 찾아다니지 마세요 — 존재하지 않습니다.

5단계: 설치 확인

이번엔 대상 프로젝트(준비물 ③번, 코드를 넣을 그 프로젝트) 폴더로 이동해서 아래를 입력합니다:

/sodam-design-kit:setup

✅ 이 화면이 보이면 성공: 명령을 입력하려고 /를 칠 때 sodam-design-kit:setup이 자동완성 목록에 나타나고, 실행하면 오류 없이 끝납니다.

여기까지 왔다면 설치는 끝났습니다! 🎉

실제로 사용해보기 (첫 실행, 5분 안에 결과 보기)

1단계: 초기 설정 (프로젝트당 딱 1번만)

대상 프로젝트 폴더에서:

/sodam-design-kit:setup

✅ 이 화면이 보이면 성공: "생성되었습니다" 같은 메시지와 함께, 그 프로젝트 폴더 안에 .design-kit이라는 새 폴더가 생깁니다.

2단계: Figma 디자인 준비 — 링크 복사하기

  1. Figma에서 코드로 만들고 싶은 화면(예: 버튼 하나)을 클릭해서 선택합니다.
  2. 화면 전체 링크가 아니라, 그 하나의 요소를 딱 선택한 상태에서 공유 링크를 복사합니다(마우스 오른쪽 클릭 → "Copy link" 또는 이와 비슷한 메뉴). 이 링크 주소 안에 node-id=라는 글자가 포함되어 있어야 정확합니다.
    • ⚠️ 자주 하는 실수: Figma 파일 전체 링크(맨 처음 열었을 때 주소창의 링크)를 그냥 복사하면 안 됩니다. 반드시 원하는 요소를 클릭해서 선택한 다음 복사해야 합니다.

3단계: 파이프라인 실행

Claude Code 대화창에서:

/sodam-design-kit:pipeline

그리고 방금 복사한 Figma 링크를 붙여넣고, "이 버튼을 코드로 만들어줘" 같은 자연어로 요청합니다.

  • AI가 자동으로 다음을 순서대로 진행합니다: ① Figma 디자인 읽기 → ② 코드 생성 → ③ 화면을 실제 브라우저에 띄워서 확인 → ④ 접근성 검사 → ⑤ 휴대폰/태블릿/PC 3가지 크기로 검사 → ⑥ 결과 기록.
  • 이 과정은 몇십 초~몇 분 걸릴 수 있습니다. 중간에 "검사에 실패해서 다시 시도합니다" 같은 메시지가 나와도 걱정하지 마세요 — 정상적인 자동 재시도 과정입니다(최대 3번까지).

4단계: 결과 확인

✅ 최종 성공 기준: AI의 답변에 PASS(통과)라는 표시가 나오고, .design-kit/reports/ 폴더 안에 새 파일(.md 확장자)이 생깁니다. 이 파일을 열어보면:

  • **PASS**라는 글자
  • 360px / 768px / 1440px, 이렇게 3가지 화면 크기의 스크린샷 경로 3줄 이 보이면 정말로 브라우저에서 확인까지 끝난 것입니다.

❌ 만약 FAIL(실패)이 나왔다면? 고장 난 게 아닙니다. 오히려 이 도구가 제대로 검사하고 있다는 증거입니다. 판정서 파일을 열어 어떤 이유로 실패했는지 확인하고, AI에게 "이 실패 이유를 보고 고쳐줘"라고 요청하면 됩니다.

자주 만나는 문제와 해결 방법 (문제/오류 대처)

이런 화면/메시지가 보여요 왜 이런가요? 어떻게 하나요?
설치는 했는데 /sodam-design-kit:setup이 자동완성에 안 떠요 Claude Code가 아직 새 플러그인을 못 알아챈 상태 창을 완전히 닫았다가 다시 켜기(새로고침 아님)
"완료가 차단되었습니다" 정상입니다. 검사에 실패했는데 AI가 "다 됐다"고 거짓말하듯 넘어가지 못하도록 일부러 막아놓은 안전장치입니다 판정서에서 실패 이유를 확인하고 다시 시도
실패(FAIL)가 계속 반복돼요 자동으로 3번까지 고쳐보는데도 안 되는 문제일 수 있어요 판정서를 열어 실패 이유를 직접 읽거나, AI에게 "이 이유를 보고 고쳐줘"라고 요청
Figma 연결이 안 돼요 로그인이 끊겼거나 권한 문제일 수 있어요 AI에게 "Figma 연결 상태를 확인해줘"라고 요청
제 컴퓨터에 저장된 .fig 파일이 안 열려요 이 도구는 Figma 계정에 저장된 파일만 읽을 수 있고, 내 컴퓨터에 있는 파일은 직접 못 읽어요 Figma 프로그램에서 그 파일을 열어 계정에 저장한 뒤, 그 링크를 사용
"포트가 충돌한다"는 메시지가 스쳐 지나가요 다른 프로그램이 같은 자리를 쓰고 있다는 뜻인데, 아무것도 안 하셔도 됩니다. 이 도구가 자동으로 다른 자리를 찾아서 계속 진행합니다
한글이 네모(□)로 깨져 보여요 글꼴이 아직 자동으로 안 챙겨지는 부분(다음 업데이트 예정) 지금 버전에서는 사용자가 대상 프로젝트의 폰트 설정을 직접 확인해야 합니다

자주 묻는 질문 (FAQ)

Q1. 저는 코딩을 전혀 모르는데 써도 되나요? A. 네. 이 가이드에 적힌 명령 2개(/sodam-design-kit:setup, /sodam-design-kit:pipeline)를 그대로 입력하고, 나머지는 전부 자연어(평소 말투)로 AI에게 요청하면 됩니다. 다만 "대상 프로젝트"라는 코드 뼈대 자체는 누군가(또는 AI에게 부탁해서) 미리 준비되어 있어야 합니다.

Q2. AI가 다 알아서 하는데, 왜 굳이 "검사"라는 게 필요한가요? A. AI도 실수를 할 수 있습니다. 이 도구는 AI가 "다 됐다"고 말하기 전에, 실제로 컴퓨터가 브라우저를 열어서 눈으로 보듯이 확인하게 만듭니다. 그래서 "말로만 됐다"가 아니라 "진짜로 확인하고 됐다"를 보장하려는 목적입니다.

Q3. 실행하다가 중간에 멈추면 어떻게 하나요? A. Claude Code 대화창에 상황을 그대로 설명하면 됩니다(예: "중간에 멈췄어요, 어떻게 해야 하나요?"). AI가 현재 상태를 확인하고 다음에 뭘 해야 할지 안내해 줄 수 있습니다.

Q4. 이 도구를 다른 사람에게 공유하거나 팔아도 되나요? A. 아니요, 현재는 안 됩니다. 이 도구 자체의 사용 허가 범위(라이선스)가 아직 정해지지 않았기 때문입니다. 자세한 내용은 README.md의 법률·저작권 항목을 꼭 읽어보세요.

Q5. 제 컴퓨터에 있는 개인 정보나 회사 자료가 어딘가로 전송되나요? A. 아니요. 이 도구는 사용자가 지정한 Figma 디자인 화면만 읽어오고, 그 외에는 아무 데이터도 외부 서버로 보내지 않습니다. 생성된 코드와 검사 기록은 전부 내 컴퓨터 안에만 저장됩니다. 다만 개인정보가 담긴 실제 Figma 파일은 이 도구에 연결하지 않는 것이 규칙입니다(연습용/가짜 데이터만 사용).
