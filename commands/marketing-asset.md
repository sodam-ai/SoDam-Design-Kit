# /sodam-design-kit:marketing-asset

> **Phase 3 1차 증분 — 2026-08-17 구현**. `03_PHASES.md` L104 범위 중 **OG 이미지 1종만** — 실제 설치 스파이크(satori+sharp를 이 PC에서 실행해 한글 렌더까지 확인)를 먼저 통과한 뒤 최소 범위로 착수했습니다. 포스터·배너·명함·SNS 카드 등 나머지 규격, `ASSET-LEDGER.csv` 이미지 확장은 다음 증분(범위 밖).

## 목적
제목(+선택 부제)을 받아 1200x630 OG(Open Graph) 이미지를 생성합니다. 코드 기반(Satori: JSX→SVG, Sharp: SVG→PNG)이라 외부 API·API 키가 필요 없습니다.

## 절차 (에이전트가 수행)

1. **[에이전트] 소재 문구 작성**: 대상 내용을 바탕으로 제목(간결하게)과 선택적으로 부제를 작성합니다. **원본 정보에 없는 사실을 지어내 광고하지 마세요** — `commands/detail-page.md`와 동일한 원칙입니다.
2. **[스크립트] 렌더+검증+배치+AI 생성 이력 기록 (한 명령)**: `node "${CLAUDE_PLUGIN_ROOT}/scripts/marketing-asset-pipeline.mjs" --project <경로> --assetType og --title "<제목>" [--subtitle "<부제>"] [--output <상대경로>]` — 이 한 명령이 다음을 전부 수행합니다:
   - P2 폰트 파이프라인의 Pretendard를 재사용(없으면 자동 다운로드, 있으면 재사용 — 무료·로컬)
   - Satori로 SVG 렌더 → Sharp로 PNG 변환
   - 규격(1200x630)·포맷(png)·용량(5MB 이하) 검증 — 실패 시 파일을 쓰지 않고 에러로 중단
   - 기본 위치 `public/design-kit-assets/og-<제목-slug>.png`에 저장(경로는 항상 프로젝트 루트 하위로 정규화 검증됨)
   - `.design-kit/AI-GENERATION-LOG.md`에 시크릿 필터를 거친 프롬프트·모델·날짜 자동 append
3. 출력 JSON의 `outputPath`를 사용자에게 안내하고, 실제로 열어서 텍스트가 잘렸거나 깨지지 않았는지(특히 긴 제목) 육안 확인을 권합니다 — 이번 증분은 자동 줄바꿈/글자 크기 조절을 하지 않습니다(아래 "안 한 것" 참조).

## 검증 게이트와의 관계 (중요 — 다른 명령과 다름)
이 파이프라인은 `verify-runner.mjs`(Playwright+axe-core)를 **쓰지 않습니다**. 이미지 산출물에는 브라우저 렌더·접근성 검사가 적용되지 않기 때문입니다(01_PRD.md·03_PHASES.md가 이미 명시한 원칙 — "웹 코드용 게이트와 별도"). 대신 `validateAsset()`이 이 소재 전용 기준(규격·포맷·용량)으로 판정하며, 이 기준을 통과하지 못하면 파일이 아예 만들어지지 않습니다 — "검증 없이 완료 아님"이라는 이 킷의 핵심 원칙은 여기서도 동일하게 적용됩니다.

## 실측 함정
- **제목이 아주 길면(2~3문장 이상) 세로로 캔버스를 넘어 마지막 줄이 잘릴 수 있습니다**(2026-08-17 실측 확인 — Satori의 flexbox 레이아웃이 가로 자동 줄바꿈은 처리하지만, 줄 수가 많아 630px 높이를 넘으면 넘친 부분이 그대로 잘립니다). `validateAsset()`은 규격·포맷·용량만 검사하고 이런 시각적 잘림은 감지하지 못하므로 **PASS 판정이 나도 이미지가 잘려 보일 수 있습니다** — 생성 후 이미지를 직접 열어 확인하세요. 제목은 짧고 간결하게 작성하는 것을 권장합니다.
- Windows/Git Bash에서 `--title`에 특수문자가 섞이면 인자 파싱이 꼬일 수 있습니다 — PowerShell 사용을 권장합니다(기존 파이프라인과 동일한 실측 함정).
